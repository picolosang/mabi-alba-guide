# 🌱 마비 알바 가이드

제작자 **LT피콜로씨** · 마비노기 아르바이트 순서·추천 보상·에린 시간 알람 오버레이

## 다운로드

**[여기를 눌러 EXE 하나만 다운로드](https://github.com/picolosang/mabi-alba-guide/releases/latest/download/MabiGuide.exe)**

[최신 버전과 변경 내용](https://github.com/picolosang/mabi-alba-guide/releases/latest)

사용자는 **MabiGuide.exe만 받으면 됩니다.** 음성·그림·설명서는 EXE 안에 있습니다.

릴리스에 함께 있는 파일은 자동 업데이트 확인용이며 따로 받을 필요 없습니다.

| 파일 | 용도 |
|---|---|
| update.xml | 새 버전·다운로드 주소·파일 확인 정보 |
| update.sig | 제작자가 서명한 업데이트인지 확인 |
| SHA256SUMS.txt | 원본 EXE와 같은 파일인지 확인할 해시값 |

## 사용법

1. EXE 실행 → 관리자 권한 요청에 동의
2. 설정에서 원하는 알바 선택
3. 가이드 시계를 게임의 에린 시간에 맞추기
4. 알바 완료 후 완료 버튼 또는 단축키 사용

| 기본 단축키 | 기능 |
|---|---|
| Alt+1 | 완료 |
| Alt+2 | 건너뛰기 |
| Alt+3 | 되돌리기 |
| Alt+4 | 다음 날 준비 화면 |
| Alt+5 | 접기 / 펼치기 |

단축키는 설정에서 바꿀 수 있습니다. 종료는 창의 X 또는 트레이 메뉴의 종료를 사용하세요.

## 주요 기능

- 현재 알바 하나씩 표시: 마을·NPC·동선·추천 보상
- 원하는 알바만 선택해서 루틴 구성
- 창 이동·잠금·투명도·접기
- 에린 시계, 지정 시간 반복 알람, 알바 음성 안내
- 마지막 선택 알바 완료 시 새싹 요정·별빛 폭죽·축하 음성
- 음성과 중앙 요정 각각 ON/OFF
- 시작 시 업데이트 알림과 수동 확인

## 업데이트

새 버전이 있으면 변경 내용을 보고 **업데이트 / 나중에**를 선택합니다.
공식 저장소에서 받은 파일의 제작자 서명과 SHA-256을 확인한 뒤 설치합니다. 설정은 유지하며 이전 EXE는 .previous로 보관합니다.

기존 1.8.3 사용자는 이번 1.9.0을 한 번 직접 받아야 이후 업데이트를 프로그램 안에서 받을 수 있습니다.

## 참고와 출처

게임에서 단축키를 받기 위해 관리자 권한으로 실행합니다. 알바 수락·이동·보고는 직접 진행합니다.
설정·메모·진행 기록은 각 PC에 저장하며, 업데이트 확인 시 GitHub에 접속합니다.
업데이트용 서명과 Windows 게시자 인증서는 별개이며, Windows 코드 서명은 아직 없습니다.
